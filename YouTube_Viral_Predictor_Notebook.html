Problem Statement

Define the problem and approach

🎯 Objective

Predict the likelihood of a YouTube video becoming viral using historical trending data from India.

  • Task Type: Binary Classification — "Viral" (1) vs "Not Viral" (0)
  • Target Variable: Videos in the top 25% of views are labelled as Viral
  • Value: Helps content creators, marketers, and brands optimize their content strategy
📌 Focus Areas: Engagement metrics (views, likes, comments), content metadata (title length, tags), and publish timing patterns.

Feature Engineering

Create · Select · Define Target Label

🔧 New Features Created

  • title_length — Number of characters in the video title
  • tag_count — Number of pipe-separated tags used
  • engagement_rate — (likes + comments) / views · captures audience interaction intensity
  • like_dislike_ratio — likes / (dislikes + 1) · sentiment signal
  • is_viral — Target: 1 if views ≥ 75th percentile (715,156), else 0
In [8]Feature Creation
# Title length
df['title_length'] = df['title'].apply(lambda x: len(str(x)))

# Tag count
df['tag_count'] = df['tags'].apply(
    lambda x: len(str(x).split('|')) if x != '[none]' else 0
)

# Engagement rate
df['engagement_rate'] = (
    (df['likes'] + df['comment_count']) / df['views'].replace(0, np.nan)
).fillna(0).clip(upper=1.0)

# Like/dislike ratio
df['like_dislike_ratio'] = df['likes'] / (df['dislikes'] + 1)

# Define viral label (top 25% of views)
threshold = df['views'].quantile(0.75)
df['is_viral'] = (df['views'] >= threshold).astype(int)

print(f"Viral threshold: {threshold:,.0f} views")
print(f"Viral: {df['is_viral'].sum()} ({df['is_viral'].mean()*100:.1f}%)")
print(f"Not Viral: {(df['is_viral']==0).sum()} ({(1-df['is_viral'].mean())*100:.1f}%)")

Model Optimization

Hyperparameter Tuning · Cross-Validation · Final Selection

⚙️ Why Random Forest?

An ensemble method combining hundreds of decision trees. Benefits:

  • Handles non-linear relationships and feature interactions
  • Robust to outliers — critical given skewed view counts
  • Provides native feature importance
  • Reduces overfitting vs single decision trees (bagging)
